Отладка расчёта

Формула и переменные прототипа 
area_one = width_mm × height_mm / 1 000 000
perimeter_one = 2 × (width_mm + height_mm) / 1000
base_piece = area_one × 1320 + perimeter_one × 1 + 0.50

raw_total = base_piece × execution_coeff × qty + 30
raw_piece = raw_total / qty
raw_piece = max(raw_piece, execution_min_piece)

price_piece = ceil(raw_piece / round_step) × round_step
final_total = price_piece × qty

Коэффициенты и ламинация внутри исполнения:
standard = 1.0; minPiece = 6.50; без ламинирования
standard_plus = 1.5; minPiece = 9.75; с защитной ламинацией
strong_glue = 2.0; minPiece = 15.00; с защитной ламинацией
premium = 3.0; minPiece = 25.00; с защитной ламинацией
individual = автоматический расчёт отключён

Для Стандарта значение ламинации определяется исполнением: без ламинирования.
Для Стандарт+, Усиленного клея и Премиума защитная ламинация включена в исполнение
и отдельно не рассчитывается — её стоимость уже учтена коэффициентом.

Для execution = individual отдельного выбора ламинации в калькуляторе нет.
Материал, ламинирование и покрытие уточняются менеджером по комментарию клиента.
